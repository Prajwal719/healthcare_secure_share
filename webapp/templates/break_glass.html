🔐 How Institutional Key Escrow Works

  • During file upload, the AES-256 data key is wrapped for the uploader and the institutional Escrow key.
  • On Break-Glass, the server verifies the emergency justification and logs an ACTION_BREAK_GLASS event.
  • The escrow service unwraps the file AES key using the Escrow Private Key and re-wraps it under your public key.
  • Your client decrypts the record directly with your private key without needing the original doctor's passphrase.
